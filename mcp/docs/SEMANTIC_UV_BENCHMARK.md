# Semantic UV Benchmark Contract

Updated: 2026-09-21
Branch: Local

REMOTE_GITHUB may prove only deterministic planning and static efficiency proxies.

Current source benchmark compares:
- explicit repeated island intent payload vs one affected island delta;
- retained placement count;
- changed/moved island count;
- atlas completion/utilization.

It must not be reported as wall-clock, memory, provider-token, or visual-quality proof.

The permanent contract requires a representative one-island change to preserve all unaffected placements and the script guard requires at least 50% serialized payload-proxy reduction on its current fixture.

LOCAL_CODE should later measure compile wall-clock and allocation cost. LIVE_BLOCKBENCH should measure native transaction latency, Undo/Redo, save/reopen, seam quality and correction rounds.
